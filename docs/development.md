# Development

## Prerequisites

- [Node.js](https://nodejs.org/) (v22.12+)
- [Rust](https://www.rust-lang.org/tools/install) (latest stable)

## Commands

```bash
# Start Electron desktop app with Hot Module Reloading (HMR)
npm run dev:desktop

# Vite dev server only (no Electron)
npm run dev

# Run tests
npm run test

# Run tests in watch mode
npm run test:watch

# Run a specific test file
npx vitest run src/stores/uiStore.test.ts

# Type-check
npx tsc --noEmit

# Build for production
npm run package

# Initialize and update git submodules (including proton-bridge)
npm run submodule:update

# Rust only (from crates/supermail-core/)
npm run build:rust
```

## Testing

- **Framework:** Vitest + jsdom
- **Setup:** `src/test/setup.ts` (imports `@testing-library/jest-dom/vitest`)
- **Config:** `globals: true` -- no imports needed for `describe`, `it`, `expect`
- **Location:** Tests are colocated with source files (e.g., `uiStore.test.ts` next to `uiStore.ts`)
- **Count:** 199 test files across stores (9), services (102), utils (20), components (56), constants (3), router (1), hooks (2), config (1), plus 4 system tests in `src/test` and 1 platform test

### Zustand test pattern

```ts
beforeEach(() => {
  useStore.setState(initialState);
});

it('does something', () => {
  useStore.getState().someAction();
  expect(useStore.getState().value).toBe(expected);
});
```

## Building

```bash
# Build for your current platform
npm run package
```

Produces native installers:
- **Windows** -- `.exe` (NSIS / portable)
- **macOS** -- `.dmg` / `.app`
- **Linux** -- `.deb` / `.AppImage`

## Email Account Setup

### Gmail (OAuth)

SuiteMail connects directly to Gmail via OAuth. You need your own Google Cloud credentials:

1. Go to [Google Cloud Console](https://console.cloud.google.com/)
2. Create a new project (or use an existing one)
3. Enable the **Gmail API** and **Google Calendar API**
4. Create OAuth 2.0 credentials (Desktop application)
5. In SuiteMail's Settings, enter your Client ID

> SuiteMail uses PKCE flow -- no client secret is required.

### Proton Mail (Bridge)

SuiteMail supports Proton Mail with end-to-end encryption via the embedded or local Proton Mail Bridge:

1. The Proton Mail Bridge source is included as a git submodule in `submodules/proton-bridge`.
2. To build the headless bridge from source, follow the build instructions in `submodules/proton-bridge/` (requires Go).
3. SuiteMail automatically detects Bridge binaries built from the submodule (`submodules/proton-bridge/` or `bin/`), as well as any existing system-installed Proton Bridge instances.
4. Click the account switcher in the sidebar → **Add Account** → **Proton Mail**.
5. Enter your Proton email address and your **Bridge Password** (generated by Bridge in Mailbox details).
6. SuiteMail verifies the local loopback IMAP and SMTP connections and encrypts your credentials locally with AES-256-GCM.

### IMAP/SMTP

For non-Gmail providers (Outlook, Yahoo, iCloud, Fastmail, etc.):

1. Click the account switcher in the sidebar → **Add IMAP Account**
2. Enter your email address and password (or app-password)
3. SuiteMail auto-discovers server settings for well-known providers
4. For other providers, enter IMAP/SMTP host, port, and security manually
5. Test connection, then save

> No Google Cloud project or Client ID needed. Passwords are encrypted with AES-256-GCM in the local database. Some providers (e.g., Gmail, Yahoo) require an app-specific password instead of your main password.

## AI Setup (Optional)

To enable AI features, add your API key for one or more providers in Settings:

- **Anthropic Claude** -- [Get API key](https://console.anthropic.com/) -- Haiku 4.5 (default), Sonnet 4, Opus 4
- **OpenAI** -- [Get API key](https://platform.openai.com/) -- GPT-4o Mini (default), GPT-4o, GPT-4.1 series
- **Google Gemini** -- [Get API key](https://aistudio.google.com/) -- 2.5 Flash (default), 2.5 Pro

After adding an API key, select which model to use for each provider in Settings > AI.
